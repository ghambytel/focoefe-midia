# focoefe-midia

Imagens públicas do perfil @focoefenoprocesso, usadas pelo Metricool para agendar os posts do Instagram.

- `nXX.jpg`: artes do lote atual (paisagens ilustradas por tema)
- `tools/scenes.py`: gera as artes a partir de um JSON com tema, frase e referência
  (`python3 tools/scenes.py novembro/posts.json saida/`)
- `novembro/posts.json`: textos, frases e referências bíblicas de novembro de 2026
